# 🛍️ Tanzeela Ameer - E-Commerce Website

A modern, responsive E-Commerce Website developed using **HTML, CSS, and JavaScript**. The website provides product browsing, category filtering, product searching, shopping cart functionality, and a contact form.

## 📌 Project Overview

This project was developed as a team assignment to practice **frontend web development** and **Git & GitHub collaboration**.

The website is designed to work smoothly on:

* 📱 Mobile devices
* 📱 Tablets
* 💻 Desktop computers

## 🚀 How to Run the Project

### Method 1 — Using VS Code

1. Download or clone the repository.
2. Open the project folder in VS Code.
3. Make sure `index.html`, `style.css`, `script.js`, and the `images` folder are present.
4. Open `index.html` in a browser.

### Method 2 — Using Live Server

1. Open the project in VS Code.
2. Install the **Live Server** extension.
3. Right-click `index.html`.
4. Select **Open with Live Server**.
5. The website will open in your browser.
